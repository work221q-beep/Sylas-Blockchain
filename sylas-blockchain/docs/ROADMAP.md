# Roadmap

1. Stabilize the Rust engine under sustained VPS load.
2. Expand receipt indexing beyond the local append-only node log.
3. Harden peer discovery and validator networking beyond the current alpha peer service.
4. Replace quorum-accounting alpha mode with audited BFT consensus and finality.
5. Add snapshots and fast state sync.
6. Add smart-contract/runtime support or explicit app-chain program model.
7. Add public JSON-RPC compatibility and SDK packages.
8. Add external price/indexer integrations for live market data.
9. Add metrics, tracing, alerting, and validator operations tooling.
10. Add fuzzing, formal review of state transitions, and external audit.
